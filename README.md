# The Sovereign Body Method

A free, evolving home for **The Sovereign Body Method**, created by **Mikey & Larrina**.

This repository will contain an accessible, local-first React reading experience for the public introduction, a 30-day starter journey, and an expandable library of the original manuals.

> **Release integrity:** The historic paid Gumroad manuals are not yet imported into this repository. We will publish their original material only after the canonical source files have been reviewed, not reconstruct their words from summaries.

The method is an educational wellness and reflective practice, not a medical treatment or substitute for individualized care.

See the `feat/free-method-react-site` pull request for the complete website implementation and deployment workflow.
