# Sovereign Body Method: source fidelity and release protocol

## Why this matters

The Sovereign Body Method was co-created by Mikey and Larrina. The original manuals and related products were historically offered on a Gumroad storefront. The goal is to make the **real original materials available free**, not to substitute generated approximations.

**The website's 30-day companion and 12 topic introductions are newly written introductory materials. They are not represented as extracted from the book.**

## Locate and review canonical source files

Historical references (not yet found in this repo):
- `The_Sovereign_Body_Method_MASTER.docx`
- `THE SOVEREIGN BODY METHOD.docx`
- `30_Day_Holistic_Health_Manual.docx`
- `Detailed_Exercise_Protocols.docx`
- Four weekly recipe sections and recipe compilations
- Other herbs/supplements and spiritual chapters

These are archival clues, not proof of current file availability or completeness.

## Release checklist

- [ ] Compare files by content and date; identify canonical editions and any supplements.
- [ ] Obtain both creators' signoff for public release and any content licensing terms.
- [ ] Preserve original authorship and copyright notices.
- [ ] Review medical, supplement, dietary, exercise and trauma-sensitive passages for safety and distinguish claims from tradition.
- [ ] Export accessible PDF and EPUB/HTML editions where appropriate.
- [ ] Add actual reviewed assets under `public/library/` (large files may require a separate public release or storage).
- [ ] Add verified metadata, links, chapter pages and downloads.
- [ ] Check mobile, offline, broken links and screen-reader navigation.
- [ ] Decide whether the Gumroad product should be set to free or point to the new site.

## Site operation

```bash
npm install
npm run dev
npm test
npm run build
```

Hosted via GitHub Pages; configure repository **Settings → Pages → Source: GitHub Actions**. The built site has a repo-relative base path.

Progress is saved only to browser local storage. No accounts, tracking or analytics are included. The Google Fonts CSS is optional, with system-font fallbacks for offline reading.
